# NaNavalha BarberShop 💈

Sistema de agendamento de serviços para barbearia, desenvolvido como projeto acadêmico.

## Android
- Java + MVVM + Data Binding
- Retrofit 2 para consumo da API
- Fluxo de agendamento em 5 passos
- Autenticação com SharedPreferences

## Backend
- Java + Tomcat 10
- Servlets REST
- MySQL (banco: barber)
